# ADR 0064 修订 1：快速修复「用作名字」只改写名字位置

- 状态：**PROPOSED**（2026-11-27，待产品负责人采纳）
- 日期：2026-11-27
- 修订对象：[ADR 0064](0064-name-escape.md) §6「LSP」第 3 项（快速修复「用作名字」）及其对 N1 的引申
- 相关：aster-cloud/aster-lang-ts#404（生产复现，ts 3.8.1）、aster-cloud/aster-lang-ts#401 / #402（零宽 E901 上的修复）

---

## 1. 现状

§6 规定快速修复「挂在关键词误作名字错误、W802 与 E808 上，把该词改为 `` `x` ``」，没有说改写哪些出现。ts 3.6.0 起的实现按 N1（转义 token 永远是名字 token）引申为「改写后该词在**所有位置**都是名字」，把文档里该词每个整词出现（字符串、注释、已有转义之外）都写成转义。

这个引申假设该词在文档里只当名字用。同一个词既作名字又作关键词很常见（zh 字段 `返回` 与 RETURN 语句；de `wenn`；hi `यदि`）：2026-11-27 生产复测 zh 入门示例，给结构体加字段 `申请金额 并且 返回 作为 文本。` 后应用修复，第 7 行正确变为 `` `返回` ``，规则体里三处 `返回「…」。` 也被改成 `` `返回`「…」。 ``，读作名字，报 E064。

## 2. 裁决（提议）

把 §6 第 3 项改为：

> 快速修复「用作名字」：挂在 §9 的关键词误作名字错误、W802 静默改名警告与 E808 上，把该词在**每个名字位置**上的出现改为 `` `x` ``——诊断处，以及引用同一名字的位置（如 `申请人.返回`）。读作关键词的出现不改写。

N1 本身不变：转义 token 永远是名字 token。修订的是它的引申——「改写后该词在所有位置都是名字」改为「改写后该词在**所有名字位置**都是名字」。

判定名字位置用编译结果，不靠词法：

1. 先只改写诊断处；
2. 用与诊断相同的词法表、别名集与租户词汇编译改写结果，落在该词其他出现上的同组诊断（关键词作名字、W802、E808）或原文没有的错误（如引用旧写法的未知字段 E801），说明那一处也在名字位置，一并改写；迭代到不动点，轮数有上限；
3. 编译时读作关键词且无诊断的出现从不改写；
4. 改写结果比原文多出错误时退回只改写诊断处；它也多出错误时不给修复。

## 3. 影响

只影响编辑器快速修复的改写范围；语法、IR、诊断码与 parity 夹具不变。实现：aster-cloud/aster-lang-ts#404 的修复 PR（ts 3.8.2 候选），每次修复的编译次数有上限（原文、诊断处与至多 4 轮扩展，共 6 次）。
