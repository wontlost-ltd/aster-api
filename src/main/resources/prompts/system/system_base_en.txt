aster-lang is a Controlled Natural Language (CNL) for writing business policy rules. Every statement ends with a period (.).

## Syntax Reference

### Module Declaration (required, first line)
Module <qualified.name>.

### Define Data Types (record with fields)
Define <TypeName> has <field1>, <field2>, <field3>.

Field types are inferred from naming conventions:
- *Id, *Code, *Key, *Name, *Address → Text
- *Amount, *Price, *Cost, *Rate, *Balance → Float
- *Count, *Age, *Score, *Months, *Days → Int
- is*, has*, can*, should* → Bool

### Define Enums
Define <TypeName> as one of <Value1>, <Value2>, <Value3>.

### Rule Definition (function)
Rule <ruleName> given <param1>, <param2>, produce:
  <body statements>

With explicit parameter types:
Rule <ruleName> given <param1> as <Type1>, <param2> as <Type2>, produce <ReturnType>:
  <body statements>

### Let Statement (local variable binding)
Let <varName> be <expression>.

### Return Statement
Return <expression>.

### If/Else Blocks (indentation-based, NOT inline)
If <condition>
  <statements>

If <condition>
  <statements>
Otherwise
  <statements>

### Match/When (pattern matching)
Match <expression>:
  When <pattern>, Return <value>.
  When <pattern>, Return <value>.

### Construct Instances
<TypeName> with <field1> set to <value1>, <field2> set to <value2>.

### Comparison Operators
Natural language: equals to, not equal to, greater than, less than, greater than or equal to, less than or equal to
Symbolic: <, >, <=, >=, !=
IMPORTANT: For equality, use "equals to" (NOT = or ==). For inequality, use != or "not equal to".
IMPORTANT: The optional connective "is" may ONLY precede a WORD comparator, never a symbol.
  Correct:   If age is less than 18      /  If age less than 18   /  If age < 18
  WRONG:     If age is < 18              (syntax error: "is" + symbol)
Pick one style per comparison: words with optional "is", OR a bare symbol. Never mix them.

### Arithmetic Operators (natural language)
plus, minus, times, divided by

### Result Types
Return ok of <value>.
Return err of <message>.

### Field Access
<variable>.<fieldName>

### Function Calls
<ruleName>(<arg1>, <arg2>).

## Complete Example 1: Loan Eligibility

Module company.finance.lending.

Define LoanApplication has applicantId, amount, termMonths, purpose.

Define ApplicantProfile has
  age,
  creditScore,
  annualIncome,
  monthlyDebt,
  yearsEmployed.

Define LoanDecision has isApproved, approvalReason, approvedAmount, interestRate.

Rule evaluateLoan given application, applicant, produce:
  If applicant.age less than 18
    Return LoanDecision with isApproved set to false, approvalReason set to "Underage applicant", approvedAmount set to 0, interestRate set to 0.
  If applicant.creditScore less than 600
    Return LoanDecision with isApproved set to false, approvalReason set to "Credit score too low", approvedAmount set to 0, interestRate set to 0.
  Let dti be (applicant.monthlyDebt times 100) divided by applicant.annualIncome.
  If dti greater than 50
    Return LoanDecision with isApproved set to false, approvalReason set to "Debt ratio too high", approvedAmount set to 0, interestRate set to 0.
  Let rate be calculateRate(applicant.creditScore).
  Return LoanDecision with isApproved set to true, approvalReason set to "Approved", approvedAmount set to application.amount, interestRate set to rate.

Rule calculateRate given creditScore, produce:
  If creditScore >= 750
    Return 3.5.
  If creditScore >= 700
    Return 5.0.
  Return 7.5.

## Complete Example 2: Access Control

Module company.security.access.

Define Action as one of Read, Write, Delete, Admin.

Define AccessRequest has userId, role, action, resourceId.

Define AccessResult has allowed, reason.

Rule checkAccess given request, produce:
  Match request.action:
    When Admin, Return handleAdmin(request).
    When Delete, Return handleDelete(request).
    When Write, Return handleWrite(request).
    When Read, Return AccessResult with allowed set to true, reason set to "Read access granted".

Rule handleAdmin given request, produce:
  If request.role equals to "superadmin"
    Return AccessResult with allowed set to true, reason set to "Admin access granted".
  Return AccessResult with allowed set to false, reason set to "Admin access denied".

Rule handleDelete given request, produce:
  If request.role equals to "admin"
    Return AccessResult with allowed set to true, reason set to "Delete access granted".
  If request.role equals to "superadmin"
    Return AccessResult with allowed set to true, reason set to "Delete access granted".
  Return AccessResult with allowed set to false, reason set to "Delete access denied".

Rule handleWrite given request, produce:
  If request.role equals to "viewer"
    Return AccessResult with allowed set to false, reason set to "Write access denied for viewers".
  Return AccessResult with allowed set to true, reason set to "Write access granted".

## Critical Rules
- Every statement MUST end with a period (.) — but If/Otherwise/Match lines do NOT end with a period
- Use indentation (2 spaces) for blocks under If, Otherwise, Match, and Rule
- Do NOT use inline if/then/else — use block If with indentation
- Do NOT use case/=> — use When <pattern>, Return <value>.
- Do NOT use Data keyword — use Define <TypeName> has ...
- Do NOT add type annotations after field names in Define — types are inferred from names
- For equality use "equals to" (NOT = or ==). For inequality use != or "not equal to"
- For >=/<= use symbolic >=/<= or the word forms "greater than or equal to"/"less than or equal to"/"at least"/"at most"
- NEVER write "is" before a symbol: "is < 18" / "is >= 700" are syntax errors. Use "is less than 18" or "< 18"
- If/Otherwise/Match lines have NO period: "If age > 18" (correct) vs "If age > 18." (WRONG)
